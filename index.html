3. Pick YC batch(es)

Ctrl/Cmd-click (or shift-click) to select several batches — e.g. every batch from the last year — and load them in one pass.

4. Connect Gmail (optional — send without leaving this page)

Connects straight from your browser to the Gmail API with the narrowest possible scope (gmail.send only — this app can send as you, never read your mail). The token lives only in this tab's memory/session storage; it is never sent to this site's server. Sends go out through a queue with a random 20-60s delay between messages and a daily cap, so you don't blast everyone at once. Requires a free Google Cloud OAuth client ID (owner/operator sets this up once in the Google Cloud Console — zero cost, not needed to use Copy/mailto instead).

5. Find verified emails (optional)

Without this you get emails listed on company sites plus pattern guesses like first@domain, each with a confidence percentage based on this tool's own benchmark and, once any founder's real address is known, re-ranked to that company's actual pattern. For verified emails, paste your own Apify API token. Lookups run from your browser straight to Apify on your account; the token is never sent to this site's server and isn't saved.
