# yc-outreach — build spec (2026-10-23)

Internal build doc. Terse, concrete, no restating self-evident code.

## Pages

### `/` — `index.html` (single static page, no router, no build step)
Purpose: pick a YC batch → get founders+emails → draft+send cold emails, all client-side.

Sections (top to bottom):
1. **Your details** — inputs: name, portfolio URL, github, resume URL. Persisted `localStorage["yc-outreach-v2"]`.
2. **Template editor** — subject input + body textarea, placeholder-insertion toolbar (`{first_name} {company} {one_liner} {batch} {my_name} {portfolio} {github} {resume}`). Line auto-drops if its only placeholder is empty.
3. **Batch picker** — `<select>` populated from `GET /api/yc?action=batches` + "Load companies" button (→ arrow/check icon, not text "Submit").
4. **Verified-email opt-in** — Apify token `<input type=password>` (never persisted, never sent to this server) + USD cap input + "Find emails" button.
5. **Toolbar** (sticky) — text search, email-status `<select>`, industry `<select>`, "hide sent" checkbox, "hiring" checkbox, Expand/Collapse-all toggle, Export CSV button (icon-only, e.g. download glyph).
6. **Company list** — one `<details>` per company: summary = name + best-email badge + top founder + batch + roles count; body = one-liner/industry/website/YC/LinkedIn/X links, open-roles list, per-founder rows (name, title, email, badge), live draft `<pre>` (subject+body), Copy-body/Copy-email/Copy-subject buttons (clipboard glyph), mailto "open in mail app" link (envelope glyph), per-company "sent" checkbox.
7. **Load more** button — paginates founder/job fetch 20 companies at a time.
8. **Footer** — GitHub star link, data-source + etiquette note.

No other pages. SEO assets added this session: `<link rel=canonical>`, favicon (inline SVG data URI), `og:*`/`twitter:*` meta, `/robots.txt`, `/sitemap.xml`.

## APIs

Single module `api/yc.py`, Vercel Python serverless function, `maxDuration=60`. No auth (public, read-only, no secrets held server-side).

- **`GET /api/yc?action=batches`**
  Request: no params. Response `200`: `[{batch: "Summer 2026", companies: 168}, ...]` sorted newest-first. Cache: `s-maxage=86400`. Source: YC Algolia facet counts on `batch` field.

- **`GET /api/yc?action=companies&batch=<Season Year>`**
  Request: `batch` validated against `BATCH_RE`. Response `200`: `[{name, slug, batch, website, one_liner, industry, team_size, launched_at}, ...]`. `400` on invalid batch. Cache: `s-maxage=3600`.

- **`GET /api/yc?action=founders&slugs=a,b,c`** (max 10, `SLUG_RE`-validated)
  Fans out via `ThreadPoolExecutor`. Response `200`: `[{slug, founders:[{name,title,linkedin,twitter}], jobs:[{title,url}], job_count, site_emails:[...], resolves:bool, email_guesses:{...}} | {slug, error}]`. Cache: `s-maxage=86400`. Per-company website check capped at `SITE_DEADLINE=4s`.

- **Apify enrichment** — not a yc-outreach endpoint. Browser calls Apify's own API (`api.apify.com/v2/acts/snipercoder~email-finder-by-name-and-domain/runs`) directly with the visitor's token. Never proxied through `api/yc.py`.

## Features

- **Email resolution ladder** (`best()`/`RANK` in `index.html`): apify-verified > apify-unverified > site-scraped (incl. Cloudflare `data-cfemail` XOR decode, `cf_decode()`) > pattern guess (`first@`, `first.last@`, `flast@`, `firstlast@`, gated on DNS resolution) > none. Data: per-company object in `ALL`/`DATA` arrays, mirrored to `localStorage["yc-outreach-v2-batch-<batch>"]`. Dependency: `api/yc.py` founders action. Status: complete.
- **Search/filter/CSV** — full-text (name/founder/one-liner/job titles), email-status filter, industry filter (`industryTop()`), hiring filter, hide-sent, CSV export of visible rows. Status: complete.
- **Sent-tracking** — keyed by YC `slug` (not display name, handles name collisions). Status: complete, regression-tested (`tests/test_sent_tracking.mjs`).
- **SEO/distribution metadata** — canonical link, favicon, OG/Twitter meta, `robots.txt`, `sitemap.xml`, GitHub-star footer CTA, README "Live" link. Status: **shipped this session** (previously stranded on stale `fork/distribution-metadata`, which predated and would have regressed the industry-filter/search/cf-decode work — reimplemented fresh on current `main` instead of merging that branch).
- **Remaining gaps (not built yet)**:
  - No rate limiting on `api/yc.py` (only `MAX_SLUGS=10` + `SITE_DEADLINE=4s` caps per-call cost; no per-IP throttle).
  - Two independent scrape implementations (`api/yc.py` vs `yc_scraper.py`/`apify_enrich.py`) share no common module — logic/bug-fix drift risk.
  - No server-side error tracking/alerting if YC changes page markup (Algolia key scrape or `data-page` JSON shape) and scraping silently breaks.
  - No Gmail-send-from-browser (removes copy/paste step) — seen in fork `lakshh07/yc-outreach`, not ported here.
  - Local `main` still ahead of `origin/main` (upstream `adityajha2005/yc-outreach`) by unpushed commits — push target for this repo is `fork` (`caelum0x/yc-outreach`), not `origin`.
